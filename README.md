## 🐈 About Me

I am a backend-focused software developer with a strong interest in building reliable, well-structured systems. My work is mainly centered around core application logic, data persistence, and system behavior rather than user interfaces. I enjoy designing solutions where correctness, clarity, and maintainability are the primary goals.

I'm currently developing REST APIs with Spring Boot, applying backend engineering concepts — authentication, database design, testing, and infrastructure — in realistic, production-shaped applications rather than simple CRUD exercises. I'm particularly interested in the reasoning behind technical decisions: why a given approach to concurrency, data modeling, or system architecture is the right trade-off for a given problem.

Before moving into API development, most of my projects were console-based or backend-oriented, which let me focus on problem-solving and technical fundamentals such as concurrency, networking, and database interaction — a foundation I still lean on heavily today.

Outside of coding, I value a calm and focused working environment, often accompanied by my cat quietly supervising from nearby.

## 🚀 Featured Project

### 🏋️ Fitness Tracker API

A REST API for tracking workouts, routines, exercises, workout sessions, and personal fitness statistics.

The project focuses on applying backend engineering concepts in a realistic Spring Boot application rather than simply implementing CRUD endpoints.

**Tech Stack:** Java 21 · Spring Boot · Spring Security · JWT · Spring Data JPA · Hibernate · PostgreSQL · Flyway · Gradle · JUnit 5 · Mockito · Testcontainers

**Features & Development:**
- ✅ JWT authentication and refresh-token rotation
- ✅ User management and role-based authorization
- ✅ Workout routines and workout sessions
- ✅ Training statistics and personal records
- ✅ Progress tracking
- ✅ PostgreSQL database design and Flyway migrations
- ✅ Unit and integration testing
- ✅ Object storage integration with MinIO
- 🚧 Asynchronous email delivery with RabbitMQ (retries, dead-letter queues)
- 🚧 Email-based account verification
- 🚧 Caching and query/index optimization
- 📋 OpenAPI / Swagger API documentation

**Status:** 🚧 Active Development

[View the project →](https://github.com/genesshoan/fitness-tracker-api)
